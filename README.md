# Bike'n You — site recréé

Site statique prêt pour GitHub Pages. UN SEUL fichier HTML autonome —
tout le CSS et tout le JavaScript sont dedans, comme dans la version qui
fonctionnait au départ. Plus aucun dossier css/ ou js/ à gérer.

## Contenu de ce lot
- `index.html` : site complet FR/EN (CSS + JS inclus dans le fichier)
- `legal.html`, `privacy.html`, `general.html` : pages légales
- `robots.txt`, `sitemap.xml` : référencement
- `SECURITY.md` : notes de sécurité

## ⚠️ Fichier manquant : assets/
Ce lot ne contient PAS le dossier `assets/` (logo, photos, favicon).
Gardez-le tel qu'il est déjà dans votre dépôt.

## ⚠️ À vérifier : l'adresse du site
D'après votre capture d'écran, votre site est actuellement en ligne à
`.../Bike-n-You/` (avec tirets). C'est l'adresse que j'ai remise partout
dans ce lot (canonical, Open Graph, robots.txt, sitemap.xml). Si ce n'est
pas la bonne adresse exacte, dites-le-moi et je corrige tout d'un coup.

## Mise en ligne
Téléversez `index.html`, `legal.html`, `privacy.html`, `general.html`,
`robots.txt` et `sitemap.xml` à la racine du dépôt GitHub, par-dessus les
anciens fichiers, en conservant `assets/`. Il n'y a plus de dossier css/
ou js/ à ajouter.
Activez GitHub Pages sur la branche `main`, dossier `/root`.

## Nouveautés de ce lot
- **Correction du plantage** : retour à un fichier unique — plus aucun
  risque d'oublier un dossier à l'upload.
- **Assistant du site** : icône remplacée par un petit robot, vocabulaire
  très largement étendu (salutations, "ça va ?", guidage quand la
  personne ne comprend pas, garantie, paiement, délais...), toujours sans
  IA générative ni donnée envoyée à un tiers.
- **Avis clients** : même contenu, même mise en page, défilement vers la
  gauche environ 2,5× plus rapide.
- **Section "Pourquoi Bike'n You"** : les trois chiffres comptent de 0
  jusqu'à leur valeur finale en un peu plus d'une seconde, synchronisés.
- Emojis des cartes Services plus visibles et distinctifs.
- Nouvelle page `general.html` (Mentions générales), mentions légales et
  politique de confidentialité réécrites.
