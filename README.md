# Bike'n You — site recréé

Site statique prêt pour GitHub Pages. Ce ZIP est désormais COMPLET : il
contient absolument tout ce qu'il faut, y compris le dossier `assets/`.

## Contenu de ce lot
- `index.html` : site complet FR/EN, un seul fichier autonome (CSS + JS
  inclus dedans, aucun autre fichier requis pour que le site fonctionne)
- `legal.html`, `privacy.html`, `general.html` : pages légales
- `robots.txt`, `sitemap.xml` : référencement
- `SECURITY.md` : notes de sécurité
- `assets/` : logo, favicon, icône iOS, 3 photos de l'atelier, 5 avatars
  d'avis clients

## Mise en ligne
Téléversez TOUT le contenu de ce dossier (fichiers ET dossier `assets/`)
à la racine du dépôt GitHub, en remplaçant les anciens fichiers. Activez
GitHub Pages sur la branche `main`, dossier `/root`.
